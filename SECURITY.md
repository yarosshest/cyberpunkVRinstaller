# Политика безопасности

## Поддерживаемая версия

Исправления безопасности выпускаются для текущей версии установщика 0.1.9.

## Сообщение об уязвимости

Не публикуйте уязвимость и чувствительные журналы в открытом issue. Используйте приватный раздел
**Security → Report a vulnerability** репозитория GitHub.

Укажите версию установщика, версию Windows, ожидаемое и фактическое поведение, а также минимальные шаги
воспроизведения. Не прикладывайте сохранения игры, токены и полный дамп памяти без согласования.
