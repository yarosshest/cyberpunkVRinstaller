# Security policy

**English** | [Русский](SECURITY_RU.md)

## Supported version

Security fixes are provided for the current 0.1.9 installer release.

## Reporting a vulnerability

Do not disclose a vulnerability or sensitive logs in a public issue. Use the repository's private
**Security → Report a vulnerability** page.

Include the installer version, Windows version, expected and actual behavior, and minimal reproduction
steps. Do not attach game saves, tokens, or a complete memory dump unless this has been agreed separately.
